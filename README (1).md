# Інтерактивний курс: Бази даних — зв’язки між таблицями (9 клас)

## Склад архіву
- `index.html` — автономний навчальний модуль українською мовою.
- `README.md` — інструкція із запуску та публікації на GitHub Pages.

## Що оновлено
- Пояснення первинного й зовнішнього ключів подано повними українськими назвами; скорочення PK/FK розшифровані у словничку.
- Типи зв’язків 1:1, 1:∞ та ∞:∞ пояснені на прикладах, таблицях і векторних схемах.
- Додано зрозуміле пояснення позначень «1» та «∞», унікальності зовнішнього ключа й ролі проміжної таблиці.
- Додано ілюстрації у дружньому для 9 класу стилі; вони вбудовані в HTML і працюють офлайн.
- Розширено кількість тренажерів: ключі, типи зв’язків, послідовність дій, пошук помилок, перевірка повторів.
- Додано практичну роботу з готовими таблицями «Учні» та «Оцінки» й інтерактивне вікно, стилізоване під Microsoft Access.
- Практикум містить інструкцію, вибір полів для зв’язку, прапорець цілісності даних і перевірку створеної моделі.
- Підсумкові тести оцінюються за 12-бальною шкалою. Звіт містить кількість спроб, час, правильні відповіді, помилки та статистику інтерактивних вправ без повторення формулювань завдань.

## Запуск локально
1. Розпакуйте архів.
2. Відкрийте `index.html` у сучасному браузері (Chrome, Edge, Firefox).
3. Зареєструйте учня через кнопку «Профіль учня» (ПІБ і клас).
4. Опрацюйте матеріал першого та другого уроків.
5. Виконайте інтерактивні вправи, практикум у стилі Access і тести.
6. Після тесту натисніть «Згенерувати звіт». HTML-звіт можна відкрити в браузері та зберегти у PDF через Ctrl+P → «Зберегти як PDF».

## Публікація на GitHub Pages
1. Створіть репозиторій, наприклад `access-relationships-grade9`.
2. Завантажте `index.html` і `README.md` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі Build and deployment виберіть **Deploy from a branch**.
5. Оберіть гілку `main` і папку `/ (root)`, натисніть Save.
6. Після публікації відкрийте адресу GitHub Pages, яку покаже GitHub.

## Важливо про Microsoft Access
Практичний інтерфейс у модулі є навчальною симуляцією, а не повним емулятором Microsoft Access і не засобом редагування файлів `.accdb`. Він відтворює логіку вибору полів та створення зв’язку. Для реальної роботи повторіть інструкцію у встановленій програмі Access. Назви команд можуть дещо відрізнятися залежно від версії та мови інтерфейсу.

## Технічні особливості
- Один HTML-файл, без зовнішніх бібліотек і CDN.
- Працює офлайн після завантаження.
- Адаптивний інтерфейс для комп’ютерів, планшетів і смартфонів.
- Drag & Drop має резервний режим: натискання картки, потім цільової зони.
- Дані учня зберігаються лише в поточній вкладці браузера під час роботи; автоматичного надсилання вчителю немає.
